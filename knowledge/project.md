# My Engineering Portfolio — Building Systems from First Principles

I am an AI and Systems Engineer who builds complex systems from the ground up to understand how they work internally. My work spans deep learning, distributed systems, computer vision, natural language processing, and full-stack AI applications.

## Core Engineering Philosophy

Rather than only using high-level frameworks and APIs, I intentionally build simplified versions of fundamental technologies to understand what happens underneath the abstraction. This approach enables me to debug effectively, design better architectures, and integrate technologies into production-ready systems.

## Project Highlights

**LLM From Scratch** — Built a GPT-style language model from the ground up using PyTorch, implementing tokenization, BPE, multi-head attention, Transformer architecture, training pipelines, and text generation algorithms.

**WebSocket From Scratch** — Implemented the WebSocket protocol from TCP sockets using Python's standard library, including handshake processing, frame encoding and decoding, masking, and client-server communication.

**LangGraph AI Agent Laboratory** — Built production-ready LLM agents with LangGraph, implementing state management, tool calling, ReAct agents, multi-agent systems, RAG, persistent memory, and FastAPI deployment.

**AI Fitness Coach** — Developed a real-time computer vision system using MediaPipe Pose, geometric feature extraction, state-machine repetition counting, and fuzzy logic for movement quality evaluation.

**Intelligent Invoice Extraction** — Created a hybrid document intelligence system combining Tesseract OCR with Donut Vision Transformer for structured invoice data extraction with automatic fallback.

**Human Performance Intelligence System** — Designed an end-to-end IoT and AI platform connecting ESP32 wearables through Kafka streaming, Cassandra storage, XGBoost stress detection, and specialized AI agents.

**B-Project** — Built a full-stack photovoltaic project management platform with Angular frontend, Node.js backend, and an XGBoost regression model for task duration prediction served through FastAPI.

**Big Data Twitter Analysis** — Deployed a 3-node Hadoop cluster with HDFS storage and MapReduce processing, exposed through a Flask REST API and Angular visualization dashboard.
